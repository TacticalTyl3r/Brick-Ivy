How publishing works

  1. Fill in the Realtor's details and select Add to draft roster.
  2. Review your roster, then select Copy roster JSON.
  3. Open the GitHub editor, replace the file contents, and commit the change.
  4. GitHub Pages updates the public Realtors page after deployment.

The Owner's Discord role will eventually control this screen. Adding a listing here does not grant access to the staff portal or change anyone's Discord roles.
